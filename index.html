개인정보처리방침

시행일: 2026년 9월 13일

오늘의 테니스 운영자 행복이는 이용자의 개인정보를 필요한 범위에서 처리하며 아래와 같이 보호합니다.

1. 처리하는 정보

기기에 저장되는 정보

레슨·게임 일지, 느낀 점, 목표, 스코어 및 그림 메모는 이용자의 기기에 저장됩니다. 앱 삭제 또는 기기 변경 전에 백업해 주세요.

로그인 및 코치 공유 시 처리되는 정보

  • Clubsmatch 로그인: 이메일 주소, 사용자 식별자 및 로그인 세션
  • 프로필: 이름, 레슨장, 회원 유형, 선택한 코치, 레슨 주기와 시작일
  • 코치 공유: 공유 대상 코치, 기록 날짜·종류·기술·레슨 회차와 이용자가 공유 칸에 직접 작성한 텍스트
  • 코치가 작성한 피드백 텍스트

비밀번호는 인증 서비스인 Supabase를 통해 처리되며 운영자가 비밀번호 원문을 조회하거나 저장하지 않습니다.

2. 이용 목적

계정 인증, 프로필과 레슨 주기 설정, 코치 연결, 이용자가 요청한 기록 공유 및 코치 피드백 제공, 오류 대응과 서비스 보안을 위해 정보를 처리합니다.

3. 보관과 삭제

기기 기록은 이용자가 앱 또는 기기의 데이터를 삭제할 때까지 보관됩니다. 서버에 저장된 프로필·공유 텍스트·피드백은 서비스 제공 기간 동안 보관되며, 공유 기록은 앱에서 공유 취소를 선택하면 삭제됩니다. 계정 및 관련 데이터 삭제를 원하면 고객지원 이메일로 요청할 수 있습니다.

4. 외부 서비스

계정 인증과 코치 공유 기능을 위해 Supabase를 이용합니다. Google 캘린더 추가 기능은 외부 캘린더 화면을 직접 여는 방식이며 앱이 Google 계정의 캘린더 정보를 수집하지 않습니다. 이 안내 웹페이지는 GitHub Pages에서 제공되며 접속 시 GitHub가 보안 및 서비스 제공을 위한 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

5. 이용자의 선택과 권리

로그인 없이 기기 내 개인 일지를 사용할 수 있습니다. 코치 공유는 기본적으로 꺼져 있으며 이용자가 코치를 선택하고 공유할 텍스트를 직접 작성한 경우에만 전송됩니다. 이용자는 공유를 취소하거나 개인정보의 열람·정정·삭제를 요청할 수 있습니다.

6. 아동의 개인정보

앱은 이용자의 나이를 확인하거나 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 보호자가 아동의 정보가 처리되었다고 판단하면 고객지원으로 삭제를 요청할 수 있습니다.

7. 방침 변경

서비스 또는 관련 법령에 따라 방침이 변경될 경우 변경 내용과 시행일을 이 페이지에 게시합니다.
