1. 처리하는 정보

레슨·게임 일지, 느낀 점, 목표, 스코어, 그림 메모, 레슨 주기와 시작일, 이용자가 설정한 이름과 레슨장 이름은 기기에 저장됩니다. 앱 삭제 또는 기기 변경 전에 필요한 기록을 백업해 주세요.

선택적 로그인 시 처리되는 정보

  • Clubsmatch 공통 계정 로그인: 이메일 주소, 사용자 식별자 및 로그인 세션

비밀번호는 인증 서비스인 Supabase를 통해 처리되며 운영자가 비밀번호 원문을 조회하거나 저장하지 않습니다. 개인 일지와 그림은 로그인만으로 서버에 업로드되지 않습니다.

2. 이용 목적

개인 테니스 기록과 레슨 주기 관리, 선택적 계정 인증, 오류 대응과 서비스 보안을 위해 정보를 처리합니다.

3. 보관과 삭제

기기 기록과 설정은 이용자가 앱 또는 기기의 데이터를 삭제할 때까지 보관됩니다. 계정 정보는 계정 이용 기간 동안 인증 서비스에서 처리되며, 앱 설정의 회원 탈퇴 또는 고객지원 문의를 통해 삭제를 요청할 수 있습니다.

이전 버전에서 서버에 저장된 프로필·공유 기록·피드백이 남아 있을 수 있습니다. 현재 앱은 코치 연결, 기록 공유 및 코치 피드백 기능을 제공하지 않으며, 이런 서버 데이터를 새로 만들거나 다른 이용자에게 전송하지 않습니다. 과거 데이터의 삭제는 회원 탈퇴 또는 아래 문의처로 요청할 수 있습니다.

4. 외부 서비스

선택적 계정 인증을 위해 Supabase를 이용합니다. Google 캘린더 추가 기능은 이용자가 외부 캘린더 화면을 직접 여는 방식이며, 오늘의 테니스가 Google 계정의 캘린더 정보를 수집하지 않습니다. 이 안내 웹페이지는 GitHub Pages에서 제공되며, 접속 시 GitHub가 서비스 제공을 위한 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

5. 이용자의 선택과 권리

로그인 없이 기기 내 개인 일지를 사용할 수 있습니다. 이용자는 앱에서 기록을 백업하거나 삭제할 수 있고, 설정에서 공통 계정 탈퇴를 진행할 수 있습니다. 개인정보의 열람·정정·삭제는 아래 문의처로 요청할 수 있습니다.

6. 아동의 개인정보

앱은 이용자의 나이를 확인하거나 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 보호자가 아동의 정보가 처리되었다고 판단하면 고객지원으로 삭제를 요청할 수 있습니다.
